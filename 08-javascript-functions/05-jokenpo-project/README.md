# Jokenpô - Modern Rock Paper Scissors

### 📝 Descrição / Description

**PT:** Um jogo moderno de Pedra, Papel e Tesoura desenvolvido com foco em manipulação limpa do DOM, lógica estruturada e design minimalista e resiliente.
**EN:** _A modern Rock, Paper, Scissors game developed with a focus on clean DOM manipulation, structured logic, and a minimalist, resilient design._

---

### 🚀 Desafios Superados / Challenges Overcome

- **Otimização de Recursos / Resource Optimization:**
  - **PT:** Consolidei a fonte **Roboto** via API oficial, eliminando requisições incompletas e resolvendo erros de rede (404) na aba Network.
  - **EN:** _Consolidated the **Roboto** font via the official API, eliminating incomplete requests and resolving network errors (404) in the Network tab._

- **Refatoração de Lógica / Logic Refactoring (DRY):**
  - **PT:** Removi arquivos redundantes para manter o código modular e limpo em um único script, reduzindo a complexidade de manutenção.
  - **EN:** _Removed redundant files to keep the code modular and clean in a single script, reducing maintenance complexity._

- **Design Resiliente / Resilient Design:**
  - **PT:** Substituí dependências externas instáveis por um **gradiente radial nativo em CSS**, aumentando a performance e garantindo estabilidade visual.
  - **EN:** _Replaced unstable external dependencies with a **native CSS radial gradient**, increasing performance and ensuring visual stability._

---
