# 03 - Function Fundamentals, Parameters & Scopes

This sub-module explores the architectural principles of execution blocks in JavaScript, focusing on parameter isolation, default value protection, and explicit dynamic return lifecycles.

### 🔑 Key Engineering Core Pillars:
*   **Encapsulated Logic Lifecycles:** Designing discrete functional containers that trigger isolated scope execution exclusively when invoked.
*   **Defensive Argument Handling:** Embedding ES6 parameter defaults (`param = default`) to safeguard processing engines against runtime `undefined` states.
*   **Void vs. Return Predicates:** Analyzing the dichotomy between side-effect operations (`void` returning `undefined`) and data-export operations utilizing the `return` statement.
*   **Data Pipeline Composition:** Compounding isolated computational steps by passing the return value of an array processor (`calculateTotalCart`) as an argument directly into an upstream financial modifier (`applyFintechDiscount`).
