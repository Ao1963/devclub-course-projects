# Master Calculator - Accessible Mathematical Engine

This standalone slate calculator implements a high-performance computational matrix combining ES6 functional flows, multi-device access vectors, and inline graphics directly inside modern JavaScript runtimes.

### 🔑 Key Engineering Deliverables:
*   **Universal Keyboard Accessibility:** Engineered a global `keydown` event listener mapping Mac hardware strokes (Numbers, Math Operators, `Backspace` for Clear, and `Enter` for Execution) into decoupled functional execution gates.
*   **Inline Vector Optimization (Zero-Latency Branding):** Purged external asset directory dependencies by injecting raw geometric XML tokens (`<svg>`) directly into the HTML tree, accelerating first-contentful-paint metrics on high-density Retina viewports.
*   **Unified Event Delegation Strategy:** Bound a single event listener to the container matrix (`.buttons-grid`) to parse dataset properties, drastically cutting runtime memory footprint overhead.
*   **Edge-Case Guardrails:** Implemented robust sanitizations (blocking multi-decimal injections per numerical sequence and capturing zero-division syntax crashes gracefully).
