# 06 - JavaScript Web: DOM Manipulation

This module focuses on the interaction between JavaScript and the browser. I am learning how to control the Document Object Model (DOM) to create dynamic and interactive user interfaces.

### 🔑 Key Learning Points:
* **DOM Selectors:** Mastering `querySelector` and `getElementById` to target HTML elements.
* **Property Manipulation:** Dynamically changing text content, HTML structures, and CSS styles via JavaScript.
* **Event Handling:** Implementing `addEventListener` to react to user actions like clicks and keyboard inputs.

### 💼 Professional Goal:
To transition from pure logic to building functional web applications where code directly impacts the user experience (UX).
