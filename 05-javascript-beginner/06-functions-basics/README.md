# 06 - Functions: Reusable Code Blocks

Functions are the building blocks of JavaScript. They allow us to encapsulate logic, making the code organized, reusable, and easy to test.

### 🔑 Key Concepts:
*   **Declaration & Invocation:** Defining a task and calling it whenever needed.
*   **Parameters & Arguments:** Passing dynamic data into functions to perform varied tasks with the same logic.
*   **The `return` Statement:** Crucial for outputting the result of a function back to the caller.
*   **DRY Principle:** "Don't Repeat Yourself"—Functions prevent code duplication and improve maintainability.

### 💼 Professional Insight:
In modern web development (React, Node.js), we focus on **Functional Programming**. This means writing small, "pure" functions that do one thing perfectly. This approach reduces bugs and makes the code much easier for teams to collaborate on.
