### 🖋️ Naming Conventions: camelCase
In JavaScript, we follow the **camelCase** standard for naming variables and functions. This practice is essential for writing "Clean Code" and ensuring global collaboration.

*   **How it works:** The first word is lowercase, and every subsequent word starts with an Uppercase letter (e.g., `userName`, `totalPrice`, `isLearningJavaScript`).
*   **Why it matters:** It improves readability and maintains consistency across the project, making the code easier to maintain for any developer in the world.
